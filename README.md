# TV en Vivo — Android Mobile v3

Rama Android móvil con interfaz rediseñada inspirada en la experiencia Smart TV.

## Diseño
- Encabezado oscuro premium con estado de conexión.
- Selector visual México / Español / Mundo / Favoritos.
- Reproductor principal tipo hero.
- Tarjeta de programación **Ahora / Siguiente**.
- Acciones rápidas: Favorito, Mini TV (PiP) y Actualizar.
- Carrusel de canales destacados.
- Buscador y filtro por categorías.
- Tarjetas modernas para todos los canales.
- Navegación inferior estilo app de streaming.

## Funciones conservadas
- Media3 / ExoPlayer con HLS y DASH.
- Catálogo remoto de IPTV-org.
- EPG cuando existe para el canal.
- Favoritos persistentes.
- Picture-in-Picture.
- Logos y encabezados de reproducción publicados en M3U.
- Exclusión de categorías para adultos.

## Rama

`android-mobile-modern`

## APK
